# Tabuada Java Swing

Projeto desenvolvido em Java durante o curso Técnico em Informática.

## Funcionalidades

- Interface gráfica com Java Swing
- Cálculo da tabuada de 1 a 10
- Validação de entrada
- Tratamento de erros
- Suporte à tecla Enter

## Tecnologias

- Java
- Java Swing
